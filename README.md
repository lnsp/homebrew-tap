# lnsp's Homebrew Tap

## TimeFinder

A Finder-style browser for Time Machine backups of other Macs — see
[lnsp/timefinder](https://github.com/lnsp/timefinder).

```sh
brew install --cask lnsp/tap/timefinder
```

TimeFinder isn't notarized by Apple, so macOS blocks its first launch (and the first launch after
each upgrade): open **System Settings › Privacy & Security** and click **Open Anyway**. It also
needs **Full Disk Access** to open Time Machine backups.
